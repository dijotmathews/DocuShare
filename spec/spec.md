A file storage and distribution application for Income Tax Consultancy. Each client will have a login with username as their PAN card number and a default password. Using the login the client will be able to access the document loaded by the Admin user under his PAN Card.  The Admin will store documents like IT Acknowledgement, Financials ( Balance Sheet, P&L, Audit Report, Tax audit report), Tax Computations and Misc reports. The client will have information like PAN Card number, Date of Incorporation, Address, Email, Contact Number, WhatsApp number. In his login, the Client will be able to access only his documents. When the Admin loads a document, it will need information like PAN, Assessment Year, Financial Year, Document Identifier, Location.  The database needs to be sqllite and should use JPA.
